# Bilibili YouTube 樣式音量條

**繁體中文** · [简体中文](README.zh-CN.md) · [English](README.en.md)

將 Bilibili 音量控制移到左側，滑鼠移入時向右展開水平音量條，並提供滾輪調整、細緻的低音量控制與可選的音量平衡。

**目前版本：1.3.1** · [安裝腳本](https://raw.githubusercontent.com/TW527E/bilibili-youtube-volume/main/bilibili-youtube-volume.user.js) · [回報問題](https://github.com/TW527E/bilibili-youtube-volume/issues)

## 安裝與更新

1. 在桌面瀏覽器安裝 [Tampermonkey](https://www.tampermonkey.net/) 或相容的使用者腳本管理器。
2. 點擊上方「安裝腳本」，在管理器中確認安裝。
3. 重新整理 Bilibili 影片頁。

若安裝連結只顯示原始碼，可在管理器建立新腳本，貼上檔案全文並儲存。已使用試用版的人，請更新原本同名腳本，避免同時啟用多份。GitHub 發布版包含更新網址，後續可由管理器檢查更新。

## 操作

| 操作 | 效果 |
| --- | --- |
| 滑鼠移到左側音量圖示 | 在播放按鈕後、時間前，向右展開 108px 音量條 |
| 拖曳音量條 | 使用三次方聽感近似刻度；50% 刻度對應 12.5% 媒體增益 |
| 在音量圖示或音量條上滾動 | 向上增加、向下減少，每個垂直滾輪事件調整 5 個百分點 |
| 點擊音量圖示 | 靜音／恢復，保留細微的低音量設定 |
| 鍵盤聚焦音量條 | 使用原生滑桿的方向鍵、Home、End 操作 |

調音量時不捲動頁面；Ctrl、Shift 與以水平為主的滾動不會被攔截。靜音時往上滾從顯示的 5% 開始，往下滾不會解除靜音。高頻觸控板事件可能讓調整較快。

此刻度不是即時音訊波形，也不是實際聲壓量測。

## 音量平衡

播放器設定首頁的「**音量平衡**」開關只切換目前影片。在「更多播放設定」→「**開啟音量平衡**」選擇預設範圍：

| 選項 | 行為 |
| --- | --- |
| 所有視頻 | 所有分區預設開啟 |
| 除了音樂分區 | **初始預設**：音樂關閉，其餘分區開啟；分區不明時先關閉 |
| 關閉 | 所有分區預設關閉 |

預設範圍保存在 Bilibili 網站的 localStorage。單片開關只保留於本次頁面；變更預設範圍會清除本頁的單片覆寫並立即套用。分區不明或音樂影片仍可手動開啟。

開關與選項沿用播放器 BUI 的 CSS 結構和主題變數，跟隨相容主題的配色；功能邏輯由腳本管理。播放器選單的自訂文字目前使用繁體中文。

### 處理方式

音訊在本機的 AudioWorklet 中處理：短時 RMS 自動增益、雙聲道連動壓縮，再限制取樣峰值。手動音量仍控制最後的輸出。

- 目標約 −12 dBFS RMS，向上增益最多約 +12 dB。
- 低於約 −40 dBFS 的訊號不持續追增益，減少拉高底噪。
- 高於約 −6 dBFS 的峰值使用 4:1 壓縮；最終取樣幅度上限為 0.98，再套用手動音量。
- 切換時短暫淡入／淡出；關閉後回到未處理訊號。

這是穩定音量的近似實作，**不是 YouTube 的專有 Stable Volume 演算法**，也不是 LUFS 正規化或 true-peak 限制器。突發尖峰碰到硬限制時仍可能失真。

## 相容性與隱私

- 主要支援桌面 Bilibili 的 BPX／HTML video 播放器，包括繁體中文影片網址。網址符合規則不代表所有播放器類型均支援。
- 已在 Chromium 類瀏覽器驗證音量控制、滾輪、設定與主題變數；使用者已完成實際環境審核。Firefox、直播、番劇、BWP 特殊播放器、多聲道內容及所有第三方音效組合尚未完整驗證。
- 無法安全接入音訊時會顯示「無法啟用」；處理器出錯時嘗試恢復直接輸出。其他音效腳本較早接管音源時，可能需要重新載入。
- 音訊不會上傳，不使用麥克風，沒有分析追蹤。頁面缺少分區資料時，會向 Bilibili 公開影片資訊 API 查詢目前 BV 號。
- 腳本不包含劇場模式、深色模式或自動關燈功能。停用後重新整理頁面，即可移除音訊路由與介面修改。

## 開發與測試

不需要建置、套件安裝或外部 JavaScript 相依套件。使用 Node.js 執行：

```sh
node --check bilibili-youtube-volume.user.js
node tests/audio.test.cjs
```

瀏覽器檢查方式見 [tests/README.md](tests/README.md)。測試包含音量刻度、滾輪、靜音、音訊路由、分區預設、設定重建及主題配色。合成音訊檢查不等同於實際聽感校準。
